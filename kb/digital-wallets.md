# Digital wallets

Lumen Reserve and Everyday can be added to Apple Pay and Google Pay in the fictional app. The wallet uses a device number. The plastic number stays masked. This chat will not read a wallet token or a full card number.

When a card is reported lost, remove the old card from each wallet before the replacement arrives. A freeze also declines new wallet purchases. Recurring charges that a merchant stored separately can still post.

Wallet purchases earn the same rewards as plastic purchases.
