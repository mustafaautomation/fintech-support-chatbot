# Travel notice

You do not have to file a travel notice for Lumen purchases inside the United States. For a trip abroad, a notice can reduce false declines. Tell a specialist the countries and the dates. This chat can explain the foreign transaction fee and can freeze the card, but it does not store a travel itinerary.

A decline abroad is not by itself fraud. If the card is missing, report it lost. If a posted charge is unfamiliar, open a dispute after the identity check.
