# Freeze and unfreeze

A freeze takes effect immediately on Lumen Reserve after the identity check in this chat. New purchases and new cash advances should decline. Recurring charges that a merchant already authorized can still post. ATM withdrawals decline while the card is frozen.

Freezing is reversible. Unfreeze restores purchasing on the same card ending 4419. A freeze is not a lost or stolen report and does not order a replacement.

If the card was reported lost, it stays frozen until the replacement is activated. Unfreeze will not turn a lost card back on.

You can ask the assistant to freeze my card or unfreeze my card. It will ask for the demo one-time code before it changes the card.
